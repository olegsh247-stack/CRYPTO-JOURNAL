# Архитектура Пулы

## Назначение

Логика и дизайн раздела «Пулы»: блок «ПУЛЫ» на листе «Ввод», листы «Пул» и «Пул Закрытые».
Это описание поведения и состава таблиц. Макросы (VBA) в этот этап не входят и делаются в самом конце.
Существующие файлы в `specs/`, `architecture/Архитектура Ввод — Основное меню.md` и прототипы `v3`–`v6` этим документом **не изменяются**.
Эталон: `CryptoJournal_Input_Prototype_v7.xlsx`.

## 1. Блок «ПУЛЫ» на листе «Ввод»

Основные данные (Дата, Актив 1, Актив 2, Пара, Протокол, Комментарий) заполняются как обычно.

| Поле | Правило |
|---|---|
| Действие | выпадающий список **Добавить, Закрыть** (проверка данных с отказом) |
| ID позиции | по умолчанию **«Новый»**: ID присвоится автоматически при записи (формат `P-0001`, счётчик раздела Пулов, правила из архитектуры Ввода, раздел 8). Можно ввести другой существующий ID (`P-0001`), чтобы добавить в конкретный пул или убрать из него (закрыть). Проверка данных пропускает только «Новый» или `P-` и номер из четырёх цифр |
| Кол-во 1 | количество Актива 1 |
| Кол-во 2 | количество Актива 2 |

Активы в блоке не повторяются: Актив 1 и Актив 2 берутся из «Основных данных».
Кнопка ЗАПИСАТЬ переносит данные на лист «Пул» (этап VBA).

## 2. Лист «Пул» (колонки B:I)

Меню: ID, Дата, Протокол, Пара | Актив 1, Актив 2 | Актив 1, Актив 2.

| Блок | Колонки | Цвет шапки |
|---|---|---|
| Основные данные | ID, Дата, Протокол, Пара | #255B78 |
| Пул | Актив 1, Актив 2 | #8064A2 |
| Частичное закрытие | Актив 1, Актив 2 | #6D568F |

Третий блок заполняется, если пул закрыт частично: в нём хранится закрытая часть количеств. У полностью открытых пулов блок пустой.

## 3. Лист «Пул Закрытые» (колонки B:N)

Стоит сразу после листа «Пул». Ярлык #6D568F, заголовок «CRYPTO JOURNAL • ПУЛ ЗАКРЫТЫЕ».

| Блок | Колонки | Цвет шапки |
|---|---|---|
| 1 | ID, Дата открытия, Дата закрытия, Протокол, Пара | #255B78 |
| 2 (открытие) | Актив 1, Актив 2 | #8064A2 |
| 3 (закрытие) | Актив 1, Актив 2 | #6D568F |
| 4 | Дельта 1, Дельта 2, Действие, Курс | #2F6F93 |

Стиль и правила те же, что у остальных листов (зебра, формат даты `ГГГГ.ММ.ДД`, числа `#,##0.00######;[Red]-#,##0.00######`).

### Расчёт (формулы)

- **Дельта 1** = Актив 1 (закрытие) − Актив 1 (открытие).
- **Дельта 2** = Актив 2 (закрытие) − Актив 2 (открытие).
- **Действие** ставится автоматически:
  - **Buy**, если Дельта 1 > 0 и Дельта 2 < 0 (Актива 1 стало больше, по факту его купили за Актив 2);
  - **Sell**, если Дельта 1 < 0 и Дельта 2 > 0 (наоборот);
  - в остальных случаях (оба актива выросли, оба упали, нет изменений, не заполнен один из активов) Действие остаётся пустым.
- **Курс** = |Дельта 2 / Дельта 1|: цена Актива 1 в Активе 2. Считается только если Действие определено.

Пример: открыли 1 XXX и 1 YYY, закрыли 1.5 XXX и 0.5 YYY → Дельта 1 = +0.5, Дельта 2 = −0.5, Действие **Buy**, Курс 1.

## 4. Этап VBA (отложено)

- кнопка ЗАПИСАТЬ: перенос данных блока «ПУЛЫ» в лист «Пул»;
- присвоение ID при «Новый» (`P-0001`, счётчик раздела, удалённые номера не повторяются);
- «Закрыть» с частичным количеством заполняет блок частичного закрытия в «Пул»; полное закрытие создаёт строку в «Пул Закрытые»;
- проверка, что ID при «Закрыть» существует, а количества не превышают остаток.

## 5. Принятые решения и открытые вопросы

Принято:
1. Действие в Пулах: Добавить, Закрыть (вместо Добавить/Удалить).
2. ID по умолчанию «Новый», вручную можно указать существующий пул.
3. Отдельный лист «Пул Закрытые» с дельтами и автоматическим Buy/Sell.
4. В листе «Пул» блок Актив 1 / Актив 2 для частичного закрытия.

Открыто:
- Колонка «Курс» в «Пул Закрытые» добавлена к заказанным (Дельта 1, Дельта 2, Действие): считается из дельт по требованию задачи. Если не нужна, её убирают.
- Что делать, если оба актива выросли или упали (комиссии, непостоянные потери): сейчас Действие и Курс пустые.
- Лист «ИТОГО ПУЛ» не менялся: в нём остались демонстрационные «Добавить/Удалить» и прежняя структура.
- Список «Добавить, Закрыть» пока записан в проверке данных ячейки, в «Справочники» не вынесен.
