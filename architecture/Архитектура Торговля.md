# Архитектура Торговля

## Назначение

Правила открытых, частично и полностью закрытых сделок раздела «Торговля»: что лежит в листах «Торговля» и «Закрытые», как делится частично закрытая сделка и почему суммы не задваиваются.
Макросы (VBA) в этот этап не входят, перенос строк между листами делает кнопка ЗАПИСАТЬ на этапе VBA. В прототипе `CryptoJournal_Input_Prototype_v7.xlsx` данные разложены вручную по этим правилам.

## 1. Правила

1. **Открытая сделка** есть только в листе «Торговля». В «Закрытых» её быть не может.
2. **Частично закрытая сделка делится на две части.** Остаток остаётся в «Торговле», закрытая часть уходит в «Закрытые». ID у обеих частей **один и тот же**.
3. **Полностью закрытая сделка** есть только в «Закрытых», из «Торговли» её строка удалена.

Принцип: каждое количество лежит ровно в одном месте, либо остатком в «Торговле», либо закрытой частью в «Закрытых».

## 2. Лист «Торговля»

- Только открытые позиции и остатки. Строка у позиции одна, ID в листе уникален.
- Заполнен **один** блок: синий (Buy, в меню «Покупка») или зелёный (Sell, в меню «Продажа»). Оба блока одной строки одновременно не заполняются: закрытая часть сразу уходит в «Закрытые».
- Колонка «Курс» содержит эффективный курс (с учётом комиссии, см. `Архитектура Ввод — Основное меню.md`, п. 3).
- «Сумма» обоих блоков (колонки H и K) считается формулой **Кол-во × Курс** (H = F × G, K = I × J); пока количество или курс не заполнены, ячейка пустая. Ячейки окрашены как автоматические поля (#FFF2CC).
- При частичном закрытии в строке уменьшается количество до остатка, сумма пересчитывается формулой по остатку.
- «Дельта 1» = Кол-во покупки − Кол-во продажи (F − I), «Дельта 2» = Сумма продажи − Сумма покупки (K − H). Пустые ячейки считаются нулём; если обе ячейки пары пусты, результат пустой. Это сводка по строке открытой позиции. Дельта закрытых частей считается в «Закрытых».
- **Break even** (колонка N, отдельный блок, #722F37) — биржевой курс, по которому закрытие остатка позиции даёт P&L = 0 с учётом комиссии закрытия. Курс в журнале уже содержит комиссию открытия (эффективный курс), поэтому нужно учесть только комиссию закрытия. Комиссия f (в процентах) — та же, что используется для «Сумма (авто)» на листе «Ввод» (`Ввод!$J$19`).
  - Позиция Buy (заполнен синий блок): Break even = Курс / (1 − f/100). Закрытие продажей по этому биржевому курсу возвращает ровно потраченную сумму: Break even × (1 − f/100) = Курс.
  - Позиция Sell (заполнен зелёный блок): Break even = Курс / (1 + f/100). Обратный выкуп по этому биржевому курсу стоит ровно полученную сумму: Break even × (1 + f/100) = Курс.
  - Единица измерения та же, что у «Курса» (котируемый актив пары). Строка без количества или курса даёт пустую ячейку.
  - Формула строки 5: `=IF(AND(ISNUMBER(F5),ISNUMBER(G5),F5>0,1-N(Ввод!$J$19)/100>0),G5/(1-N(Ввод!$J$19)/100),IF(AND(ISNUMBER(I5),ISNUMBER(J5),I5>0),J5/(1+N(Ввод!$J$19)/100),""))`.
  - Пример: T-0001, Buy 0.1 BTC, курс в журнале 62 124 (биржевой 62 000 + комиссия 0.2%) → Break even 62 248.50 (+0.4% к биржевому курсу покупки: комиссия за вход и за выход). Пример Sell: T-0005, курс 598.8 → Break even 597.60.
  - Break even считается по текущему значению комиссии: если комиссия изменится, значения в уже записанных строках пересчитаются.

## 3. Лист «Закрытые»

- Строка = закрытая часть сделки или сделка, закрытая полностью. Блоки: открытие (синий, Buy) и закрытие (зелёный, Sell), ориентация та же, что в «Торговле».
- ID может повторяться: у одной сделки по строке на каждое закрытие. Различить такие строки можно по дате закрытия.
- «Дельта 1» = Сумма (зелёный блок) − Сумма (синий блок) на одинаковом количестве. «Дельта 2» = Дельта 1 / Сумма (синий блок) × 100.
- P&L, P&L% и Break even пока пусты: правила расчёта не заданы.

## 4. Выделение частично закрытых сделок

Строки частично закрытых сделок подсвечены бледным фоном **#FDE9D9** в обоих листах («Торговля» B:M, «Закрытые» B:Q). Выделение работает автоматически (условное форматирование): строка подсвечивается, если её ID есть в обоих листах. Когда сделка закрывается полностью и уходит из «Торговли», подсветка в «Закрытых» пропадает.

## 5. Итоги без задвоения

«ИТОГО Торговля» берёт значения по паре из двух листов:
- **Кол-во и Сумма** (синий и зелёный блок) = остатки из «Торговли» + закрытые части из «Закрытых». Один и тот же объём не попадает в итог дважды, потому что на двух листах он не лежит.
- **Курс** = средневзвешенный курс по количеству из обоих листов.
- **Дельта 1** = сумма «Дельта 1» из «Закрытых» по паре. **Дельта 2** = Дельта 1 / сумма синего блока закрытых частей × 100. Пока по паре нет закрытых частей, дельты пустые.
- P&L, P&L% и Break even пусты.

Список пар вписан вручную, формулы в свободных строках готовы.

## 6. Что сделает этап VBA

- ЗАПИСАТЬ при закрытии («ID закрыть»): уменьшает количество в строке «Торговли» или удаляет строку (полное закрытие), создаёт строку в «Закрытых».
- Проверки: «ID закрыть» должен существовать в «Торговле», закрываемое количество не больше остатка.
- ID в «Торговле» не повторяются; для «Закрытых» повтор разрешён.

## 7. Открыто

- Нужна ли в «Закрытых» отдельная колонка «Закрытие №» вместо различения по дате закрытия.
- Правила расчёта P&L и P&L% (Break even введён только в «Торговле», в «Закрытых» и «ИТОГО Торговля» колонка Break even пока пуста).
- «Лэндинг», «ИТОГО Лэндинг» и «ИТОГО» пока остаются со старыми демо-данными, правила закрытых сделок для них не вводились.
