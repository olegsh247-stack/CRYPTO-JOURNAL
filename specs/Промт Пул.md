# Промт — лист «Пул»

## Назначение

Подробный промт для ассистента: как построить, проверить и дорабатывать лист «Пул» в `CryptoJournal_Input_Prototype_v7.xlsx`. Промт самодостаточен: по нему лист можно воспроизвести с нуля. Общие правила проекта — `prompts/Промт проекта.md`, дизайн — `specs/Дизайн Торговля и ИТОГО Торговля.md` (вкладка «Пул»), соседний лист — `specs/Промт ИТОГО ПУЛ.md`. Если документы расходятся: визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## 1. Роль листа

Лист «Пул» — журнал **пулов ликвидности**. **Одна строка = один пул**: в ней живут и открытие (сколько активов внесено), и закрытие (сколько активов возвращено), и разница между ними. Отдельного листа закрытых пулов нет.

Пул закрывается **один раз и целиком**. Частичного закрытия в модели нет: закрытие записывается в ту же строку, строка остаётся на листе.

Строки листа появляются из блока «ПУЛЫ» листа «Ввод» (кнопка ЗАПИСАТЬ). Макросы (VBA) и рабочие кнопки делаются в самом конце, в прототипе строки внесены вручную по правилам ниже.

## 2. Геометрия и общие правила оформления

- Колонка A — поле шириной 2.5. Таблица занимает колонки **B:K**.
- Строки 1–2: полоса заголовка B1:K2 (объединена), заливка #255B78, белый Calibri 16 Bold, текст `CRYPTO JOURNAL • ПУЛ`. Высота строк 21.
- Строка 3: узкий интервал, высота 10, **пустая** (двухуровневого меню «Открыто / Закрыто» нет, оно убрано как неудобное). Строка 4: меню одной строкой, высота 28, белый Calibri 11 Bold Italic, по центру.
- Строки данных с 5-й по 12-ю, высота 22. Зебра: нечётные строки #FFFDF3, чётные белые. Текст #244E62, Calibri 11, по центру, без переноса, тонкая рамка #6F9EB3.
- Между блоками: в шапке толстый белый просвет, в строках данных средняя линия #255B78.
- Сетка скрыта, ярлык вкладки #8064A2, ориентация печати альбомная, вписать по ширине, область печати A1:K13.
- Закреплены строка меню и колонка ID (панель на C5). Масштаб 100%.
- Автофильтр на строке меню: B4:K12 (кнопки у всех колонок).
- Дата: `ГГГГ.ММ.ДД`. Числа: `#,##0.00######;[Red]-#,##0.00######` (отрицательные красным).

## 3. Колонки и блоки

| Блок | Колонки | Заголовок в меню | Цвет шапки | Что внутри |
|---|---|---|---|---|
| 1. Основные данные | B, C, D, E | ID, Дата, Протокол, Пара | #255B78 | ID `P-0001`, дата открытия, протокол пула, пара `ETH/BTC` |
| 2. Открыто | F, G | **Открыто**, Актив 2 | #2F6F93 | F = количество Актива 1, G = количество Актива 2 при открытии |
| 3. Закрыто | H, I | **Закрыто**, Актив 2 | #5E9E72 | H = количество Актива 1, I = количество Актива 2 при закрытии |
| 4. Дельта | J, K | Дельта 1, Дельта 2 | #8064A2 | Результат закрытия по каждому активу |

Заголовки блоков «Открыто» и «Закрыто» стоят прямо над первой колонкой блока (в ней Актив 1), вторая колонка блока называется «Актив 2». Что есть Актив 1 и Актив 2, определяет пара: в `ETH/BTC` Актив 1 = ETH, Актив 2 = BTC.

Ширины колонок: B 8, C 13, D 14, E 14, F 14, G 14, H 11, I 11, J 13, K 13.

Вводимые вручную поля (ID, Дата, Протокол, Пара, Открыто, Закрыто) — заливка по зебре. Дельты — формулы, заливка тоже по зебре (как Дельта в «Торговле»).

## 4. Правила заполнения

1. Строка = один пул. ID уникален (`P-0001`, нумерация раздела отдельная, удалённые номера не используются повторно).
2. Блок «Открыто» заполняется при открытии и **остаётся заполненным после закрытия**: по нему считается Дельта.
3. Блок «Закрыто» пуст, пока пул открыт. Закрытие заполняет оба значения (H и I) сразу.
4. Открытый пул: F, G заполнены; H, I, J, K пустые. Закрытый пул: заполнены все колонки.
5. Строка остаётся на листе и после закрытия; никуда не переносится.
6. Сортировка по умолчанию — по колонке «Пара».

## 5. Формулы (строки 5–12)

Формулы Дельты стоят в J и K строк 5–12, в пустых строках дают пустую ячейку. Строка 5 как образец:

- **Дельта 1 J5** = Актив 1 Закрыто − Актив 1 Открыто:
  `=IF(AND(ISNUMBER(F5),ISNUMBER(H5)),ROUND(H5-F5,8),"")`
- **Дельта 2 K5** = Актив 2 Закрыто − Актив 2 Открыто:
  `=IF(AND(ISNUMBER(G5),ISNUMBER(I5)),ROUND(I5-G5,8),"")`

Дельта считается только когда есть и «Открыто», и «Закрыто» (то есть пул закрыт). Округление до 8 знаков убирает «хвосты» чисел с плавающей точкой. Формулы совместимы с Excel 2021.

### Смысл Дельты

Дельта показывает, сколько каждого актива стало больше или меньше после закрытия пула (комиссии пула, непостоянные потери, изменение цены). Единицы — сами активы, а не деньги: Дельта 1 в ETH, Дельта 2 в BTC.

- Дельта 1 > 0 и Дельта 2 < 0: Актива 1 стало больше, Актива 2 меньше — по факту Актив 1 купили за Актив 2.
- Дельта 1 < 0 и Дельта 2 > 0: наоборот — Актив 1 продали за Актив 2.
- Оба знака одинаковые: условной сделки нет (комиссии, непостоянные потери); на листе «ИТОГО ПУЛ» блок «Сделка» в этом случае пустой.

## 6. Связь с листом «Ввод» (логика для макросов, позже)

Блок «ПУЛЫ» на «Вводе»: Действие (H14, список «Добавить, Закрыть»), ID позиции (H15, формат `P-0001`), Кол-во 1 (J14), Кол-во 2 (J15). Остальные данные берутся из основных данных: Дата (B6), Актив 1 / Актив 2 / Пара (B9, C9, D9), Протокол (B12).

| Действие | Что делает ЗАПИСАТЬ на листе «Пул» |
|---|---|
| Добавить | создаёт новую строку: новый ID (максимальный номер раздела + 1), Дата, Протокол, Пара из основных данных; Кол-во 1 → «Открыто» Актив 1 (F), Кол-во 2 → «Открыто» Актив 2 (G) |
| Закрыть (закрытие пула) | находит строку по ID позиции; Кол-во 1 → «Закрыто» Актив 1 (H), Кол-во 2 → «Закрыто» Актив 2 (I); Дельты считаются формулами |

Проверки макроса: ID при закрытии существует; пул ещё не закрыт (H и I пусты); оба количества заполнены. Макросы в прототипе не используются, значения внесены вручную.

## 8. Проверки после любой правки

1. Пересчитать таблицу: ошибок (`#NAME?`, `#VALUE!`, `#REF!`, `#DIV/0!`) нет ни на одном листе.
2. У каждого закрытого пула Дельта 1 = H − F и Дельта 2 = I − G; у открытых пулов Дельты пустые.
3. Блок «Закрыто» заполнен целиком (H и I) либо пуст целиком.
4. Строка 3 пустая, меню в строке 4 с заголовками «Открыто», «Актив 2», «Закрыто», «Актив 2».
5. Свод на «ИТОГО ПУЛ» совпадает с суммами по листу «Пул» (см. `specs/Промт ИТОГО ПУЛ.md`).
6. Документация (`specs/`, `README.md`) совпадает с файлом, в репозитории одна рабочая версия таблицы.
7. После каждого изменения файла присылать актуальный xlsx в чат.

## 9. Чего не делать

- Макросы (VBA), рабочие кнопки, события.
- Возвращать двухуровневое меню в строке 3 и отдельный лист «Пул Закрытые».
- Переносить закрытый пул в другой лист или удалять строку при закрытии.
- Менять основной дизайн других листов и вносить изменения без команды пользователя.
- Лишние цвета и декор вне палитры из `Дизайн Ввод.md`.

## 10. Открытые вопросы

- Частичное закрытие пула в модели не предусмотрено; нужно ли оно, решается отдельно.
- Колонка даты одна (дата открытия); дата закрытия не хранится.
- Действие закрытия на «Вводе» называется «Закрыть» (список «Добавить, Закрыть»), переименовано из «Удалить».
- Формулы Дельты стоят только в строках 5–12; при добавлении строк макросом их нужно продлить вниз.
- Протоколы PancakeSwap и Orca из демо добавлены в «Справочники» (список: Binance, Bybit, OKX, Uniswap, AAVE, Raydium, PancakeSwap, Orca); остальное наполнение справочника отложено.
- Дельта выражена в самих активах; оценка в деньгах (по курсу активов) не считается.
