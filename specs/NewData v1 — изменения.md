# NewData v1 — изменения относительно CryptoJournal.xlsm

Файл: `NewData v1.xlsm` (чистый образец). Остальные промты и спецификации описывают `CryptoJournal.xlsm`; в чём NewData v1 отличается, записано здесь. Если документы расходятся — для NewData v1 верно это описание.

## 1. ID числовой
- Поля «ID позиции» (Торговля, Лэндинг) и «ID пула» принимают `T-456` / `L-456` / `P-456` или просто `456` (целое от 1). Проверка ввода на листе «Ввод» и в макросе.
- Хранится как `Буква-0456` (минимум 4 цифры): `T-456` и `T-0456` — один и тот же ID.
- ID нет ни в журнале, ни в «Закрытых»: ЗАПИСАТЬ спрашивает подтверждение и открывает новую позицию (пул — только при «Добавить»). ID уже есть в «Закрытых»: отказ. Закрытие или увеличение несуществующего ID: отказ.
- Автоматические ID пропускают занятые номера. Счётчики на «Справочниках» — только целые числа ≥ 0.
- «Статус» на «Вводе»: «Новая (ID вручную)», «Новый пул (ID вручную)», «ID занят».

## 2. Автодобавление пар и монет
- Событие книги `Workbook_SheetChange` (`ThisWorkbook.cls.bas`) → `PairsOnChange`: новая пара в «Истории» (колонка B) попадает в «ИТОГО»; в «Торговле» и «Лэндинге» (E) — в свой «ИТОГО …» и «ИТОГО»; в «Пуле» — в «ИТОГО ПУЛ»; в «Закрытых» — по букве ID.
- ЗАПИСАТЬ делает то же; монеты пары добавляются в лист «БАЛАНС» и в «Монеты» («Справочники», колонка I).
- Это отменяет правило «пары из Истории вписываются в ИТОГО вручную» из `Промт История.md`.

## 3. Лист «БАЛАНС»
Колонки B:E: Монета, Пришло, Ушло, Дельта; заголовок `CRYPTO JOURNAL • БАЛАНС`, строки 5–300, оформление как «ИТОГО». Для пары X/Y: покупка — пришёл X (Кол-во), ушёл Y (Сумма); продажа наоборот. Источники: «Торговля», «Лэндинг», «Закрытые», «История» (суммы с комиссией); «ИТОГО …» не суммируются (двойной счёт). Монета вводится вручную или добавляется макросом. Сверка с «ИТОГО» выполнена при создании, расхождений нет.

## 4. Оформление и видимость
- Дельта 1, Дельта 2, Break even — жирный курсив (данные строк 5–300).
- Ширина колонок подобрана по содержимому с запасом (колонка «Статус» на «Вводе» — 16).
- «Справочники» и «История» скрыты.

## 5. Чистый образец
Журналы, списки пар, «БАЛАНС», «История» пусты; счётчики ID = 0; «Монеты» — 17 исходных, «Протокол» — 8 исходных; Комиссия 0,2.
