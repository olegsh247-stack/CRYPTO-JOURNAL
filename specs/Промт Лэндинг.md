# Промт — лист «Лэндинг»

## Назначение

Подробный промт для ассистента: как построить, проверить и дорабатывать лист «Лэндинг» в `CryptoJournal_Input_Prototype_v7.xlsx`. Лист «Лэндинг» — **точная копия листа «Торговля»**: ничего нового не придумывается, все правила те же. Этот промт дублирует `specs/Промт Торговля.md` с поправками на раздел «Лэндинг» (буква ID, закрытые сделки в общем листе «Закрытые»). Промт самодостаточен: по нему лист можно воспроизвести с нуля. Общие правила проекта — `prompts/Промт проекта.md`, дизайн — `specs/Дизайн Торговля и ИТОГО Торговля.md`, логика сделок — `architecture/Архитектура Торговля.md`. Если документы расходятся: визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## 1. Роль листа

Лист «Лэндинг» хранит **только открытые позиции раздела «Лэндинг»** и остатки частично закрытых сделок. Закрытые сделки Лэндинга вручную переносятся в общий лист «Закрытые» (ID `L-…`), отдельного листа закрытых у Лэндинга нет. Подсветка частично закрытых сделок (#FDE9D9) строится так же, как на «Торговле»: по ID из листа «Закрытые».

Строки листа появляются из листа «Ввод» (кнопка ЗАПИСАТЬ). Макросы (VBA) и рабочие кнопки делаются в самом конце, в прототипе строки внесены вручную по правилам ниже.

## 2. Геометрия и общие правила оформления

- Колонка A — поле шириной 2.5. Таблица занимает колонки **B:N**.
- Строки 1–2: полоса заголовка B1:N2 (объединена), заливка #255B78, белый Calibri 16 Bold, текст `CRYPTO JOURNAL • ЛЭНДИНГ`. Высота строк 21.
- Строка 3: узкий интервал, высота 10.
- Строка 4: меню одной строкой, высота 28, белый Calibri 11 Bold Italic, по центру.
- Строки данных с 5-й, высота 22. Зебра: нечётные строки #FFFDF3, чётные белые. Текст #244E62, Calibri 11, по центру, без переноса, тонкая рамка #6F9EB3.
- Между блоками: в шапке толстый белый просвет, в строках данных средняя линия #255B78.
- Сетка листа скрыта, ярлык вкладки #5E9E72, ориентация печати альбомная, вписать по ширине, область печати A1:N17.
- Закреплены строка меню и колонка ID (панель на C5).
- Масштаб листа 100%. Автофильтр на строке меню оставлен (кнопки у всех колонок, диапазон B4:N16).
- Дата: `ГГГГ.ММ.ДД`. Числа: `#,##0.00######;[Red]-#,##0.00######` (отрицательные красным).

## 3. Колонки и блоки

| Блок | Колонки | Цвет шапки | Что внутри |
|---|---|---|---|
| 1. Основные данные | B ID, C Дата, D Протокол, E Пара | #255B78 | ID вида `L-0001`, дата сделки, протокол, пара `ETH/USDT` |
| 2. Покупка (Buy) | F Покупка (кол-во), G Курс, H Сумма | #2F6F93 | Заполняется только для позиции Buy |
| 3. Продажа (Sell) | I Продажа (кол-во), J Курс, K Сумма | #5E9E72 | Заполняется только для позиции Sell |
| 4. Дельта | L Дельта 1, M Дельта 2 | #8064A2 | Сводка по строке |
| 5. Break even | N Break even | #722F37 | Курс безубытка |

Ширины колонок: B 8, C 13, D 14, E 14, F 11, G 13, H 14, I 11, J 13, K 14, L 13, M 13, N 17 (N шире остальных: Break even показывается с восемью знаками, при меньшей ширине вместо числа будет ###).

Вводимые вручную поля (ID, Дата, Протокол, Пара, Покупка, Курс, Продажа, Курс) — заливка по зебре. Автоматические поля (H, K) — заливка #FFF2CC.

## 4. Правила заполнения

1. Строка = одна открытая позиция. ID в листе уникален: `L-0001`, нумерация отдельная для Лэндинга, удалённые ID не используются повторно.
2. Заполнен **один** блок: синий (Buy) или зелёный (Sell). Оба блока одной строки одновременно не заполняются.
3. Колонки «Курс» (G и J) содержат **эффективный курс** с учётом комиссии: Buy = курс × (1 + комиссия/100), Sell = курс × (1 − комиссия/100). Комиссия в процентах берётся с листа «Ввод».
4. Частичное и полное закрытие — как в «Торговле»: остаток остаётся в этом листе, закрытая часть уходит в общий лист «Закрытые» с тем же ID `L-…`, полное закрытие удаляет строку. До этапа VBA перенос делается вручную.
5. Строки частично закрытых сделок (ID есть и в «Лэндинге», и в «Закрытых») подсвечены фоном #FDE9D9 в колонках B:N (условное форматирование, диапазон B5:N200, формула `AND($B5<>"",COUNTIF(Закрытые!$B$5:$B$200,$B5)>0)`). В «Закрытых» такие строки подсвечиваются по ID из «Торговли» и «Лэндинга».

## 5. Формулы (строки 5–200, в прототипе заполнены 5–16)

Формулы идентичны «Торговле», стоят во всех строках таблицы, в том числе в пустых, и показывают пустую ячейку, пока не хватает данных. Строка 5 для примера:

- **Сумма покупки H5:** `=IF(AND(ISNUMBER(F5),ISNUMBER(G5)),F5*G5,"")`
- **Сумма продажи K5:** `=IF(AND(ISNUMBER(I5),ISNUMBER(J5)),I5*J5,"")`
- **Дельта 1 L5** = Кол-во покупки − Кол-во продажи: `=IF(COUNT(F5,I5)=0,"",N(F5)-N(I5))`
- **Дельта 2 M5** = Сумма продажи − Сумма покупки: `=IF(COUNT(H5,K5)=0,"",N(K5)-N(H5))`
- **Break even N5:**
  `=IF(AND(ISNUMBER(F5),ISNUMBER(G5),F5>0,1-N(Ввод!$J$19)/100>0),G5/(1-N(Ввод!$J$19)/100),IF(AND(ISNUMBER(I5),ISNUMBER(J5),I5>0),J5/(1+N(Ввод!$J$19)/100),""))`

### Break even: определение

Break even — **биржевой курс**, по которому закрытие остатка позиции даёт P&L = 0 с учётом комиссии закрытия. Курс в журнале уже содержит комиссию открытия, поэтому дополнительно нужно учесть только комиссию закрытия. Комиссия f (в процентах) — та же, что используется для «Сумма (авто)» на листе «Ввод».

| Позиция | Формула | Проверка |
|---|---|---|
| Buy (заполнен блок F:H) | `G / (1 − f/100)` | продажа по Break even: `BE × (1 − f/100) = G`, возвращается ровно потраченное |
| Sell (заполнен блок I:K) | `J / (1 + f/100)` | выкуп по Break even: `BE × (1 + f/100) = J`, тратится ровно полученное |

Единица та же, что у «Курса» (котируемый актив пары). Строка без количества или курса даёт пустую ячейку. Break even считается по текущему значению комиссии: при её изменении значения пересчитываются.

### Примеры (комиссия 0.2%)

| ID | Позиция | Курс в журнале | Break even |
|---|---|---|---|
| L-0001 | Buy 0.1 BTC/USDT | 62 124 (биржевой 62 000) | 62 248.50 |
| L-0002 | Buy 1 ETH/USDT | 3 206.40 | 3 212.83 |
| L-0005 | Sell 3 BNB/USDT | 598.80 | 597.60 |
| L-0010 | Sell 30 SOL/USDT | 149.70 | 149.40 |

Демо-данные листа те же, что на «Торговле», с буквой `L` вместо `T` в ID.

## 6. Связи с другими листами

- «Ввод» → «Лэндинг»: строки появляются по кнопке ЗАПИСАТЬ (этап VBA). Блок ЛЭНДИНГ на листе «Ввод» устроен иначе, чем блок ТОРГОВЛЯ (поля Действие/Операция, Кол-во, Курс (авто), Сумма): как они ложатся в колонки Покупка/Продажа, Курс и Сумма, решается на этапе VBA. Для Break even формула читает комиссию с листа «Ввод».
- «Лэндинг» → «ИТОГО Лэндинг»: свод по паре из этого листа (`specs/Промт ИТОГО Лэндинг.md`).
- Закрытые сделки Лэндинга уходят в лист «Закрытые» (ID `L-…`); «ИТОГО Торговля» к Лэндингу не относится.

## 7. Проверки после любой правки

1. Пересчитать таблицу, ошибок (`#NAME?`, `#VALUE!`, `#REF!`, `#DIV/0!`) нет ни на одном листе.
2. Лист совпадает с «Торговлей» по структуре, формулам, форматам и данным (кроме заголовка и буквы ID).
3. Break even проверить обратным расчётом: для Buy `BE × (1 − f/100) = Курс`, для Sell `BE × (1 + f/100) = Курс`.
4. Заполнен только один блок (Buy или Sell) в каждой строке, ID в листе не повторяются, все ID начинаются с `L-`; подсветка #FDE9D9 охватывает B:N.
5. Документация (`specs/`, `architecture/`, `README.md`) совпадает с файлом, в репозитории одна рабочая версия таблицы.
6. После каждого изменения файла присылать актуальный xlsx в чат.

## 8. Чего не делать

- Подключать лист «Закрытые» к формулам листа «Лэндинг»: он общий, в нём лежат и закрытые сделки Торговли.
- Менять основной дизайн других листов, COLUMN_MAP и основной журнал.
- Вносить изменения без команды пользователя.
- Лишние цвета и декор вне палитры из `Дизайн Ввод.md`.
