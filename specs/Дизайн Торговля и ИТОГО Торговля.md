# Дизайн — вкладки 2–9: «Торговля», «ИТОГО Торговля», «Лэндинг», «ИТОГО Лэндинг», «Пул», «ИТОГО ПУЛ», «Закрытые», «ИТОГО», «Справочники»

Только дизайн. Формулы, VBA и бизнес-логика не затрагиваются, значения в прототипе демонстрационные.
Стиль — как у листа «Ввод» (палитра и шрифты из `Дизайн Ввод.md`).
Написание: везде **Лэндинг / ЛЭНДИНГ** (в том числе на листе «Ввод»).

## Общее для всех вкладок

- Колонка A — поле (2.5). Таблица начинается с колонки B.
- Строки 1–2: полоса заголовка, #255B78, белый, Calibri 16, Bold: «CRYPTO JOURNAL • <НАЗВАНИЕ ЛИСТА>».
- Строка 3: узкий интервал (10). Строка 4: меню одной строкой, высота 28, белый Bold Italic Calibri 11, по центру.
- Строки данных с 5-й, высота 22. Зебра: #FFFDF3 и белый. Текст #244E62, Calibri 11, по центру, без переноса, тонкая рамка #6F9EB3.
- ID — текст с буквой раздела: `T-0001` (Торговля, Закрытые демо), `L-0001` (Лэндинг), `P-0001` (Пул); в демо-данных так же.
- Дата — формат DD.MM.YYYY (в рабочей версии единый формат `ГГГГ.ММ.ДД`, см. `architecture/`). Числа — `#,##0.00######;[Red]-#,##0.00######` (отрицательные красным).
- Закреплены строка меню и первая колонка (панель на C5). Фильтров и сортировки (выпадающих стрелок) на строке меню нет, они убраны на всех листах. Исключение по закреплению: на листе «ИТОГО ПУЛ» закреплена только строка меню (панель на A5).
- Меню разбито на цветные блоки. Между блоками в шапке толстый белый просвет, в строках данных — средняя линия #255B78.
