# Дизайн Ввод

## Назначение

Это подробный промт для создания отдельного визуального Excel-прототипа интерфейса листа «Ввод» проекта Crypto Trading Journal.

На этом этапе создаётся только дизайн-тест. Не подключать существующие формулы, VBA, ссылки, бизнес-логику или основной workbook.

## 1. Главная задача

Создать отдельный тестовый Excel-файл-прототип интерфейса листа «Ввод».

Проверить:
- расположение блоков;
- размеры;
- цвета;
- шрифты;
- пропорции;
- удобство ввода;
- визуальную иерархию.

Не менять основной журнал и не переносить дизайн в него.

## 2. Общая концепция

Современный профессиональный финансовый Excel-интерфейс без перегруженности.

Основной принцип:

**Слева — Основные данные. Справа — Разделы операций.**

Не использовать:
- dashboard с графиками;
- большое количество карточек;
- декоративные элементы;
- лишние иконки;
- чрезмерно округлённые блоки;
- большое количество цветов.

Главное — простая, аккуратная Excel-форма, а не декоративный dashboard.

Фон — белый.

Рабочая область — ориентировочно B:H.

## 3. Верхняя шапка

Диапазон примерно B1:H2.

Текст:

**CRYPTO JOURNAL • ВВОД**

Цвет: #255B78.

Шрифт:
- Calibri;
- 15–16 pt;
- Bold;
- белый.

Выравнивание:
- горизонтально слева;
- вертикально по центру.

## 4. Левая часть — ОСНОВНЫЕ ДАННЫЕ

Слева сделать отдельный вертикальный блок.

Основные данные НЕ располагать горизонтальным рядом. Каждое поле должно иметь понятную пару «название → окно ввода».

Заголовок:

**ОСНОВНЫЕ ДАННЫЕ**

Ориентировочно B3:C3.

Цвет: #2F6F93.

Шрифт:
- белый;
- Bold;
- Italic;
- 11–12 pt.

## 5. Поля блока «Основные данные»

Создать следующие поля:

1. **Наименование**
   - пример: BTC / USDT

2. **Дата**
   - пример: 04.10.2026

3. **Биржа / протокол**
   - пример: Binance

4. **Специальная**
   - пример: Нет

5. **Комментарий**
   - пример: Пробная операция

Названия полей:
- #2F6F93;
- белый;
- Bold;
- Italic;
- 10–11 pt.

Окна ввода:
- #FFFDF3;
- текст #244E62;
- Calibri 10–11 pt;
- тонкая рамка #6F9EB3.

## 6. Правая часть — РАЗДЕЛЫ

Справа создать отдельный большой блок.

Заголовок:

**РАЗДЕЛЫ**

Ориентировочно E3:H3.

Цвет: #2F6F93.

Шрифт:
- белый;
- Bold;
- Italic;
- 11–12 pt.

## 7. Торговля и Лендинг

Ключевое требование:

**ТОРГОВЛЯ и ЛЕНДИНГ должны располагаться горизонтально рядом, а не друг под другом.**

Пример композиции:

ТОРГОВЛЯ | ЛЕНДИНГ

Оба блока должны иметь одинаковую визуальную ширину и высоту.

### ТОРГОВЛЯ

Заголовок:
**ТОРГОВЛЯ**

Цвет: #2F6F93.

Внутри визуально показать:
- Действие;
- Количество;
- Курс;
- Сумма.

Демонстрационное состояние:
- Buy;
- 0.50;
- 62000;
- 31000.

Все значения демонстрационные. Расчётов нет.

### ЛЕНДИНГ

Заголовок:
**ЛЕНДИНГ**

Цвет: #2F6F93.

Внутри показать:
- Действие;
- Количество;
- Курс;
- Сумма.

Пример:
- Операция;
- 1000;
- 1.00;
- 1000.

Все значения демонстрационные.

## 8. Блок ПУЛЫ

Под Trading/Lending создать широкий блок на всю ширину правой части.

Заголовок:

**ПУЛЫ**

Цвет заголовка: #8064A2.

Фиолетовым должен быть прежде всего заголовок/акцент, а не весь блок.

Внутри визуально показать:
- Действие;
- Актив 1;
- Количество 1;
- Актив 2;
- Количество 2;
- Позиция.

Допускается компактная группировка этих полей.

## 9. Блок СПЕЦИАЛЬНЫЕ

Ниже создать широкий блок.

Заголовок:

**СПЕЦИАЛЬНЫЕ**

Цвет: #6D568F.

Внутри показать:
- Тип операции;
- Параметры;
- Комментарий.

Использовать ту же визуальную логику, что и для «Пулы».

## 10. Общая цветовая система

Использовать ограниченную палитру:

- Основной тёмно-синий: #255B78
- Основной синий: #2F6F93
- Светло-молочный: #FFFDF3
- Текст: #244E62
- Границы: #6F9EB3
- Пулы: #8064A2
- Специальные: #6D568F
- Записать: #5E9E72

Не добавлять большое количество дополнительных цветов.

Не использовать градиенты.

## 11. Шрифты

Основной шрифт:

**Calibri**

Названия полей:
- Bold;
- Italic;
- 10–11 pt.

Заголовки разделов:
- Bold;
- Italic;
- 11–12 pt;
- белый.

Главный заголовок:
- Bold;
- 15–16 pt;
- белый.

Значения:
- обычный;
- 10–11 pt;
- #244E62.

## 12. Поля ввода

Все поля должны визуально выглядеть как настоящие Excel input fields.

Использовать:
- светло-молочную заливку;
- тонкую рамку;
- одинаковую визуальную высоту;
- вертикальное выравнивание по центру.

Не использовать толстые рамки.

Не делать поля чрезмерно высокими.

## 13. Нижняя часть — управление

Создать блок статуса.

Заголовок:

**СТАТУС**

Демонстрационное значение:

**Готово к вводу**

Справа разместить две большие визуальные кнопки:

### ЗАПИСАТЬ

Цвет: #5E9E72.

Текст:
- белый;
- Bold.

### ОЧИСТИТЬ

Цвет: #2F6F93.

Текст:
- белый;
- Bold.

## 14. Кнопки

Кнопки пока НЕ должны работать.

Не подключать:
- VBA;
- макросы;
- формулы;
- события;
- действия при нажатии.

Они нужны только для оценки внешнего вида.

## 15. Buy / Sell / Pools

В визуальном тесте предусмотреть состояния:

### Торговля
- Buy;
- Sell.

### Пулы
- Добавить;
- Удалить/убрать.

### Специальные
- Специальная операция.

На данном этапе это только визуальные состояния, без настоящего переключения.

## 16. Категорически не делать

На этом этапе НЕ делать:
- графики;
- диаграммы;
- KPI;
- статистику;
- P&L;
- BEP;
- формулы;
- VBA;
- макросы;
- гиперссылки;
- автоматические расчёты;
- рабочие кнопки;
- подключение к основному журналу;
- изменение основного workbook;
- изменение COLUMN_MAP;
- изменение спецификаций;
- изменение бизнес-логики.

Не менять существующие формулы и ссылки.

## 17. Композиция

Экран должен визуально читаться следующим образом:

Верх:
**CRYPTO JOURNAL • ВВОД**

Левая часть:
**ОСНОВНЫЕ ДАННЫЕ**
- Наименование
- Дата
- Биржа / протокол
- Специальная
- Комментарий

Правая часть:
**РАЗДЕЛЫ**

Верхний ряд справа:
**ТОРГОВЛЯ | ЛЕНДИНГ**

Ниже:
**ПУЛЫ**

Ещё ниже:
**СПЕЦИАЛЬНЫЕ**

Внизу:
**СТАТУС | ЗАПИСАТЬ | ОЧИСТИТЬ**

ASCII-схема:

## 18. Визуальный баланс

Обязательно проверить:
- левая колонка не слишком узкая;
- правая часть не перегружена;
- Trading и Lending равны по ширине;
- Pools и Specials шире;
- поля имеют одинаковую визуальную высоту;
- заголовки выровнены;
- интервалы между блоками одинаковые;
- достаточно белого пространства;
- интерфейс не выглядит набором разрозненных карточек;
- цвета используются как навигация, а не как украшение.

Внутри:
- один лист;
- название листа: **Ввод**;
- только визуальный прототип;
- без рабочей логики.

Файл предназначен для открытия в Excel и визуальной оценки.

После создания не изменять основной файл журнала и репозиторий.

Это тест дизайна перед дальнейшей интеграцией.

## 20. Критерий успеха

При открытии Excel пользователь должен сразу понимать:

1. слева находятся основные данные;
2. справа находятся разделы;
3. сверху справа — Торговля и Лендинг рядом;
4. ниже — Пулы;
5. ещё ниже — Специальные;
6. светлые области — места ввода;
7. тёмно-синие области — названия;
8. внизу — управление формой.

Главный принцип:

**Простой, аккуратный, удобный Excel-интерфейс, а не декоративный dashboard.**
