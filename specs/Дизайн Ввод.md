# Дизайн Ввод

## Назначение

Общий дизайн листа «Ввод» проекта Crypto Trading Journal: концепция, палитра, шрифты, композиция. Подробные описания блоков:
- левый блок — `Дизайн Ввод — Основные данные.md`;
- правый блок — `Дизайн Ввод — Разделы.md`;
- логика полей — `architecture/Архитектура Ввод — Основное меню.md`.

Если описания расходятся, приоритет у двух уточняющих файлов `Дизайн Ввод — ...`.

## 1. Концепция

Современный профессиональный финансовый Excel-интерфейс без перегруженности: **слева — Основные данные, справа — Разделы операций**.

Не использовать: графики и dashboard, много карточек, декор, лишние иконки, чрезмерно округлённые блоки, градиенты, много цветов.

Фон — белый. Главное — простая, аккуратная Excel-форма.

## 2. Верхняя шапка

Диапазон B1:J2, текст **CRYPTO JOURNAL • ВВОД**, цвет #255B78, Calibri 15–16 Bold, белый, слева, по центру по вертикали.

## 3. Левая часть — ОСНОВНЫЕ ДАННЫЕ

Вертикальный блок, у каждого поля пара «название → окно ввода». Поля: Дата, Актив 1, Актив 2, Пара (авто), Протокол, Комментарий. Подробности в `Дизайн Ввод — Основные данные.md`.

## 4. Правая часть — РАЗДЕЛЫ

Сверху ТОРГОВЛЯ и ЛЭНДИНГ рядом, одинаковой ширины и высоты; ниже ПУЛЫ; ниже ОБРАТНЫЙ РАСЧЁТ; внизу СТАТУС, ЗАПИСАТЬ и ОЧИСТИТЬ. Правый блок — четыре равные колонки. Подробности в `Дизайн Ввод — Разделы.md`. Блока «СПЕЦИАЛЬНЫЕ» нет.

## 5. Палитра

- Тёмно-синий: #255B78 (шапка, основные данные)
- Синий: #2F6F93 (названия полей, заголовки блоков)
- Светло-молочный: #FFFDF3 (окна ввода)
- Текст: #244E62
- Границы: #6F9EB3
- Зелёный: #5E9E72 (ТОРГОВЛЯ, ЛЭНДИНГ, ЗАПИСАТЬ)
- Фиолетовый: #8064A2 (ПУЛЫ)
- Бледно-жёлтый: #FFF2CC (автоматические поля: «Пара (авто)», суммы и курс, считаемые формулами)
- Бледно-персиковый: #FDE9D9 (подсветка частично закрытых сделок в журналах)
- Тёмно-бордовый: #722F37 (P&L, «ИТОГО ПУЛ»)

Не добавлять другие цвета.

## 6. Шрифты

Calibri. Названия полей: Bold, Italic, 10–11 pt. Заголовки разделов: Bold, Italic, 11–12 pt, белый. Главный заголовок: Bold, 15–16 pt, белый. Значения: обычный, 10–11 pt, #244E62.

## 7. Поля ввода

Выглядят как настоящие Excel input fields: светло-молочная заливка, тонкая рамка, одинаковая высота, вертикальное выравнивание по центру. Без толстых рамок. Автоматические поля — заливка #FFF2CC, ячейка заблокирована. Лист защищён без пароля, редактируются только окна ввода.

## 8. Кнопки

ЗАПИСАТЬ (#5E9E72) и ОЧИСТИТЬ (#2F6F93): белый Bold. Пока не работают, макросы делаются в самом конце.

## 9. Чего пока не делать

Графики, диаграммы, KPI, статистику, P&L, макросы (VBA), рабочие кнопки, события, подключение к основному журналу, изменение COLUMN_MAP. Формулы допускаются только для согласованных автоматических полей.

## 10. Композиция

```
+--------------------------------------------------------------+
|                     CRYPTO JOURNAL • ВВОД                    |
+------------------------+-------------------------------------+
| ОСНОВНЫЕ ДАННЫЕ        | РАЗДЕЛЫ                             |
| Дата                   | ТОРГОВЛЯ          | ЛЭНДИНГ         |
| Актив 1 | Актив 2 | Пара| Действие, Кол-во, | Действие, ...   |
| Протокол               | Курс, Сумма (авто)| Сумма, Курс (авто) |
| Комментарий            | ПУЛЫ                                |
|                        | ОБРАТНЫЙ РАСЧЁТ                     |
| СТАТУС                 | [ ЗАПИСАТЬ ]   [ ОЧИСТИТЬ ]         |
+------------------------+-------------------------------------+
```

Это ориентир композиции.

## 11. Визуальный баланс

Проверять: левая колонка не слишком узкая; правая часть не перегружена; Торговля и Лэндинг равны по ширине; поля одинаковой высоты; заголовки выровнены; интервалы между блоками одинаковые; достаточно белого пространства; цвета служат навигацией, а не украшением.

## 12. Эталон

`CryptoJournal_Input_Prototype_v7.xlsx` (лист «Ввод»).

## 13. Критерий успеха

При открытии Excel сразу понятно: слева основные данные; справа разделы; сверху Торговля и Лэндинг рядом; ниже Пулы и Обратный расчёт; светлые области — места ввода, бледно-жёлтые — автоматические поля; внизу управление формой.
