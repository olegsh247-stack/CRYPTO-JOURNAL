# Дизайн Ввод

## Назначение

Общий дизайн листа «Ввод» проекта Crypto Trading Journal (финальный файл `CryptoJournal. Test m2.xlsm`): концепция, палитра, шрифты, композиция. Подробности:
- основные данные — `Дизайн Ввод — Основные данные.md`;
- разделы, обратный расчёт, кнопки — `Дизайн Ввод — Разделы.md`;
- логика полей и макрос — `architecture/Архитектура Ввод — Основное меню.md`.

При расхождении приоритет у двух уточняющих файлов.

## 1. Концепция

Профессиональный финансовый Excel-интерфейс без перегруженности. Всё на одной сетке из шести колонок B:G: сверху горизонтальная полоса **Основные данные**, ниже три раздела рядом (**Торговля | Лэндинг | Пул**), ниже **Обратный расчёт** с комиссией и кнопками, внизу пояснения.

Не использовать: графики, dashboard, декор, градиенты, много цветов. Фон белый.

## 2. Шапка

Диапазон B1:G2, текст **CRYPTO JOURNAL • ВВОД**, заливка #255B78, Calibri 15–16 Bold, белый, слева, по центру по вертикали.

## 3. Палитра

- Тёмно-синий #255B78 — шапка
- Синий #2F6F93 — названия полей, заголовки основных данных и обратного расчёта
- Светло-молочный #FFFDF3 — окна ввода
- Текст #244E62; границы #6F9EB3
- Зелёный #5E9E72 — Торговля, Лэндинг, кнопка ЗАПИСАТЬ
- Фиолетовый #8064A2 — Пул
- Тёмно-красный #8B1A1A — кнопка ОЧИСТИТЬ
- Бледно-жёлтый #FFF2CC — автоматические поля («Пара», суммы, курс, Кол-во в обратном расчёте), а также шапка Min/Max на листе «Пул»
- Бледно-персиковый #FDE9D9 — подсветка частично закрытых сделок
- Тёмно-бордовый #722F37 — P&L, «ИТОГО ПУЛ», проблемные значения статуса
- Серый #D9D9D9 / текст #808080 — недоступные разделы (условное форматирование)

Других цветов не добавлять.

## 4. Шрифты

Calibri. Названия полей: Bold Italic 10–11. Заголовки блоков: Bold Italic 11–12, белый. Значения: 10–11, #244E62. Кнопки: белый Bold 14. Пояснения: чёрный, размер 10.

## 5. Поля ввода

Светло-молочная заливка, тонкая рамка, одинаковая высота, выравнивание по центру. Автоматические поля — #FFF2CC, заблокированы. Лист защищён без пароля; редактируются только окна ввода.

## 6. Композиция

```
+--------------------------------------------------------------+
|                   CRYPTO JOURNAL • ВВОД                      |
| ОСНОВНЫЕ ДАННЫЕ: Дата | Актив 1 | Актив 2 | Пара | Протокол | Статус |
| ТОРГОВЛЯ (B:C)   | ЛЭНДИНГ (D:E)    | ПУЛ (F:G)              |
| ОБРАТНЫЙ РАСЧЁТ: Сумма | Курс | Кол-во | Комиссия | ЗАПИСАТЬ | ОЧИСТИТЬ |
| Пояснения                                                    |
+--------------------------------------------------------------+
```

## 7. Визуальный баланс

Колонки одинаковой ширины (16), равные поля по высоте, одинаковые интервалы, цвет служит навигацией. Печать A1:H25.

## 8. Эталон

`CryptoJournal. Test m2.xlsm`, лист «Ввод». Прежний прототип `CryptoJournal_Input_Prototype_v7.xlsx` лежит в `archive/`.

## 9. Критерий успеха

Сразу понятно: сверху основные данные со статусом; три раздела рядом, недоступные подсвечены серым; светлые окна — ввод, бледно-жёлтые — авто; внизу калькулятор, комиссия и две кнопки.
