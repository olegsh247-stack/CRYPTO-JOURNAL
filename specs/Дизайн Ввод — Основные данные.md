# Дизайн Ввод — блок «ОСНОВНЫЕ ДАННЫЕ»

## Назначение

Уточнение к `Дизайн Ввод.md`: состав и геометрия блока основных данных листа «Ввод» (финальный файл m2). Логика — `architecture/Архитектура Ввод — Основное меню.md`. При расхождении с `Дизайн Ввод.md` приоритет у этого файла.

## 1. Геометрия

Горизонтальная полоса на всю ширину B:G: заголовок в строке 3, названия полей в строке 4, окна ввода в строке 5.

| Колонка | Название (строка 4) | Окно (строка 5) |
|---|---|---|
| B | Дата | B5, формат `yyyy.mm.dd` (пример 2026.10.04) |
| C | Актив 1 | C5 (пример ETH) |
| D | Актив 2 | D5, список «Монеты» (пример BTC) |
| E | Пара (авто) | E5, `АКТИВ1/АКТИВ2`, Bold, заливка #FFF2CC |
| F | Протокол | F5, список из «Справочников», **необязателен** |
| G | Статус | G5, формула (показывает, что сделает ЗАПИСАТЬ) |

Поля «Комментарий», «Тип» убраны.

## 2. Оформление

- Заголовок «ОСНОВНЫЕ ДАННЫЕ» (B3:G3): #2F6F93, белый, Calibri 12, Bold Italic.
- Названия полей: #2F6F93, белый, Calibri 10, Bold Italic.
- Окна ввода: #FFFDF3, текст #244E62, Calibri 11, рамка #6F9EB3.
- Статус: значения-проблемы («Два раздела», «Нет Кол-ва», «Нет ID» и т. п.) выделяются бордовым #722F37.
- Подсказки при вводе актива не делаются.

## 3. Чего не делать

Лишние цвета, декор, поле «Комментарий».

## 4. Эталон

`CryptoJournal.xlsm`, лист «Ввод».
