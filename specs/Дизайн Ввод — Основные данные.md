# Дизайн Ввод — колонка «ОСНОВНЫЕ ДАННЫЕ»

## Назначение

Уточнение к `Дизайн Ввод.md`: окончательный состав и геометрия левого блока листа «Ввод».
Только дизайн. Формулы, VBA, макросы и бизнес-логика не затрагиваются.
Если этот файл расходится с `Дизайн Ввод.md` в части левого блока — приоритет у этого файла.
Правый блок описан в `Дизайн Ввод — Разделы.md`.

## 1. Геометрия

Ширина блока «Основные данные» = **x**. Блок состоит из четырёх равных колонок **B:E** (каждая x/4).

| Элемент | Доля ширины | Ячейки |
|---|---|---|
| Дата | x | B5:E5 (название), B6:E6 (ввод) |
| Актив 1 | x/4 | B8 (название), B9 (ввод) |
| Актив 2 | x/4 | C8 (название), C9 (ввод) |
| Пара (авто) | x/2 | D8:E8 (название), D9:E9 (ввод, объединены) |
| Протокол | x | B11:E11 (название), B12:E12 (ввод) |
| Комментарий | x | B14:E14 (название), B15:E19 (ввод, объединены, высокое окно) |

Поле «Тип» убрано.
Актив 1, Актив 2 и Пара стоят в одной строке слева направо.
Справа от блока — разделитель (колонка F) и блок «РАЗДЕЛЫ» (G:L).

## 2. Поля сверху вниз

1. **Дата** — пример: 04.10.2026.
2. **Актив 1** (пример ETH) | **Актив 2** (пример BTC) | **Пара** (результат ввода Актив 1 / Актив 2, пример ETH/BTC).
3. **Протокол** — пример: Binance. Список из «Справочников».
4. **Комментарий** — пример: Пробная операция.

Поля «Тип», «Наименование», «Специальная» в этом блоке не используются.

## 3. Оформление

- Заголовок «ОСНОВНЫЕ ДАННЫЕ» (B3:E3): #2F6F93, белый, Calibri 12, Bold, Italic.
- Названия полей: #2F6F93, белый, Calibri 10, Bold, Italic. Название стоит над окном ввода.
- Между названиями Актив 1 / Актив 2 / Пара — тонкая белая разделительная линия.
- Окна ввода: заливка #FFFDF3, текст #244E62, Calibri 11, тонкая рамка #6F9EB3.
- «Пара» в окне ввода — Bold (показывается как результат), заливка #FFF2CC (автоматическое поле), подпись «Пара (авто)».
- Комментарий: выравнивание по левому верхнему углу, перенос текста.
- Объединённые окна ввода (D12:E12, B15:E19 и широкие поля): рамка только по внешнему контуру, внутри объединения линий нет.
- Высота строк одинаковая (22), между полями — пустая строка-интервал.
- Нижний край блока (Комментарий) выровнен по нижнему краю блока «ОБРАТНЫЙ РАСЧЁТ».

## 4. Чего не делать

- Формулы (в том числе для «Пара» — пока обычный текст), VBA, макросы, события.
- Лишние цвета и декор вне палитры из `Дизайн Ввод.md`.
- Изменение основного журнала, COLUMN_MAP и бизнес-логики.
