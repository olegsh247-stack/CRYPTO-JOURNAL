# Промт — лист «ИТОГО»

## Назначение

Промт для ассистента: как построить, проверить и дорабатывать лист «ИТОГО» в `CryptoJournal_Input_Prototype_v7.xlsx`. Общие правила проекта — `prompts/Промт проекта.md`, дизайн — `specs/Дизайн Торговля и ИТОГО Торговля.md`, расчёты по разделам — `specs/Промт ИТОГО Торговля.md` и `specs/Промт ИТОГО Лэндинг.md`. Если документы расходятся: визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## 1. Роль листа

«ИТОГО» — общий свод по парам **по Торговле и Лэндингу вместе** (с учётом листа «Закрытые»). Источники — только листы «ИТОГО Торговля» и «ИТОГО Лэндинг»: все закрытые части и остатки уже учтены в них, поэтому «ИТОГО» журналы и «Закрытые» напрямую не читает. Лист «ИТОГО ПУЛ» сюда не входит (пулы считаются отдельно). Вручную вписывается только список пар в колонке B.

## 2. Геометрия и оформление

Лист оформлен как «ИТОГО Торговля»: колонки B:M, заголовок `CRYPTO JOURNAL • ИТОГО` (B1:M2), строки данных 5–300 (высота 22, зебра условным форматированием), меню в строке 4, блоки и цвета те же (Основные данные #255B78, Покупка #2F6F93, Продажа #5E9E72, Дельта #8064A2, P&L #722F37), числа `#,##0.00######;[Red]-#,##0.00######`. В прототипе 21 пара (строки 5–25, по алфавиту, объединение списков «ИТОГО Торговля» и «ИТОГО Лэндинг»); строки 26–300 свободны, формулы в них уже стоят.

## 3. Формулы (строка 5 как образец, строки 5–300)

Пара в колонке B ищется в колонке B листов «ИТОГО Торговля» и «ИТОГО Лэндинг» (диапазоны 5–300), значения складываются через `SUMIFS`. Обозначение: `SI(X)` = `SUMIFS('ИТОГО Торговля'!$X$5:$X$300,'ИТОГО Торговля'!$B$5:$B$300,$B5)+SUMIFS('ИТОГО Лэндинг'!$X$5:$X$300,'ИТОГО Лэндинг'!$B$5:$B$300,$B5)`.

| Колонка | Формула |
|---|---|
| C Покупка | `=IF($B5="","",IF(SI(C)=0,"",SI(C)))` |
| E Сумма покупки | `=IF(C5="","",SI(E))` |
| D Курс покупки | `=IF(C5="","",E5/C5)` (средневзвешенный) |
| F Продажа | `=IF($B5="","",IF(SI(F)=0,"",SI(F)))` |
| H Сумма продажи | `=IF(F5="","",SI(H))` |
| G Курс продажи | `=IF(F5="","",H5/F5)` |
| I Дельта 1 | `=IF($B5="","",IF(AND(C5="",F5=""),"",ROUND(SI(I),8)))` |
| J Дельта 2 | то же с `SI(J)` |
| K P&L | сумма K обоих листов «ИТОГО» по паре (результат полностью закрытых позиций Торговли и Лэндинга); у каждой пары из списка есть значение, 0 если закрытых позиций нет |
| L P&L% | K / стоимость полностью закрытых позиций пары × 100; стоимость = Σ MIN(Кол-во покупки, Кол-во продажи) × Курс покупки по строкам «Закрытых» этой пары, чей ID уже нет ни в «Торговле», ни в «Лэндинге»; 0, если стоимость равна 0 |
| M Break even | та же формула, что в «ИТОГО Торговля» (`specs/Промт ИТОГО Торговля.md`, п. 4), на итогах этого листа |

Формулы совместимы с Excel 2021, динамические массивы не используются.

## 4. Смысл

Курсы эффективные (комиссия внутри). Break even считается **по общим количествам и средним курсам пары** (Торговля + Лэндинг как одна позиция). P&L и P&L% — по полностью закрытым позициям (сумма двух «ИТОГО»), см. `architecture/Архитектура Торговля.md`, раздел 9. Остаток пары = Покупка − Продажа, Break even считается по нему с комиссией закрытия `Ввод!$J$19`.

## 5. Проверки

1. Пересчёт без ошибок (`#NAME?`, `#VALUE!`, `#REF!`, `#DIV/0!`).
2. Для каждой пары Покупка, Продажа и обе суммы равны сумме значений «ИТОГО Торговля» и «ИТОГО Лэндинг».
3. Пара, которой нет ни в одном из двух листов, даёт пустые ячейки. Новую пару нужно вписать и в «ИТОГО Торговля» / «ИТОГО Лэндинг» (если её там нет), иначе она не попадёт в свод.

## 6. Чего не делать

Макросы, пулы в этом листе, ссылки напрямую на «Торговля», «Лэндинг» и «Закрытые», автоматический список пар формулами.

## 7. Эталон
