# Дизайн Ввод — блоки «ТОРГОВЛЯ», «ЛЭНДИНГ», «ПУЛ», «ОБРАТНЫЙ РАСЧЁТ»

## Назначение

Уточнение к `Дизайн Ввод.md`: геометрия нижней части листа «Ввод» (финальный файл m2). Логика — `architecture/Архитектура Ввод — Основное меню.md`.

## 1. Сетка

A — поле (2.5), B:G — шесть колонок по 16. Высоты строк: 1–2 — 21; 6, 14, 18 — 14 (интервалы); 16–17 — 26; 19–24 — 34.

## 2. Порядок блоков сверху вниз

1. Основные данные (строки 3–5).
2. Заголовки разделов (строка 7): ТОРГОВЛЯ B7:C7, ЛЭНДИНГ D7:E7 — #5E9E72; ПУЛ F7:G7 — #8064A2. Поля в строках 8–13.
3. ОБРАТНЫЙ РАСЧЁТ (строки 15–17) и кнопки.
4. Пояснения B19:G24.

Каждый раздел: название поля слева (B, D, F), окно ввода справа (C, E, G).

## 3. ТОРГОВЛЯ (C8:C13) и ЛЭНДИНГ (E8:E13)

| Строка | Торговля | Лэндинг |
|---|---|---|
| 8 | Действие (Buy/Sell) | Действие (Buy/Sell) |
| 9 | Кол-во | Кол-во |
| 10 | Курс | Сумма |
| 11 | Сумма (авто) | Курс (авто) |
| 12 | ID позиции | ID позиции |
| 13 | Закрыть (Частично / Полностью) | Закрыть (Частично / Полностью) |

Авто-поля: заливка #FFF2CC, заблокированы. Торговля: Сумма = Кол-во × Курс × (1 ± Комиссия/100), Buy «+», Sell «−»; Курс — биржевой, без комиссии. Лэндинг: Курс = Сумма / Кол-во (8 знаков), комиссия не применяется. «Закрыть» — выпадающее меню, заполняется только вместе с ID; «Частично» списывает введённое Кол-во, «Полностью» закрывает весь остаток. Формат чисел `#,##0.00######`. В демо-состоянии файла окна ввода пусты.

## 4. ПУЛ (G8:G13, подписи F8:F13)

Вертикально: Действие (Добавить / Частично / Закрыть), ID пула, Кол-во 1, Кол-во 2, Min, Max. Min и Max — оба или ни одного (пусто = Web2); могут быть дробными и отрицательными, Min < Max. Активы берутся из «Основных данных».

## 5. ОБРАТНЫЙ РАСЧЁТ (B15:G17)

Заголовок B15:G15, #2F6F93. Названия в строке 16, значения в строке 17:

| B | C | D | E | F:G |
|---|---|---|---|---|
| Сумма (31000) | Курс (62000) | Кол-во (авто) | Комиссия, % (0,2) | кнопки |

Кол-во = Сумма / (Курс × (1 − Комиссия/100)), #FFF2CC. Блок — калькулятор, в журнал не пишется. Комиссия общая для всей книги.

## 6. Кнопки

ЗАПИСАТЬ (F16:F17): #5E9E72, ОЧИСТИТЬ (G16:G17): #8B1A1A; белый Bold 14. Макросы `WriteEntry` и `ClearInput` (рабочие). Кнопки — прозрачные прямоугольники поверх ячеек.

## 7. Пояснения

B19:G24, объединены, чёрный шрифт, размер 10: режимы ID, правила «Закрыть», курс, Min/Max, кнопки, «Протокол не обязателен».

## 8. Выпадающие списки

Действие в Торговле/Лэндинге — `Список_Действие_Торговля` (Buy, Sell); Закрыть — Частично/Полностью; Пул — Добавить/Частично/Закрыть; Протокол — `Список_Протокол`; Актив 2 — `Список_Монеты`.

## 9. Чего не делать

Графики, KPI, изменение COLUMN_MAP журналов, дополнительные цвета.
