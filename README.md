# CRYPTO-JOURNAL

Crypto Trading Journal: журнал сделок в Excel (торговля, лэндинг, пулы ликвидности). Репозиторий содержит рабочий Excel-прототип, описание дизайна и архитектуру логики.

## Статус

Этап прототипа и архитектуры. Интерфейс и согласованная логика полей готовы в таблице; **макросы (VBA) и рабочие кнопки делаем в самом конце**. Целевая версия Excel — 2021.

## Основной файл

`CryptoJournal_Input_Prototype_v7.xlsx` — единственная рабочая версия. Старые версии удалены, они сохранились в истории git.

| Лист | Назначение |
|---|---|
| Ввод | Форма ввода: основные данные слева, разделы (Торговля, Лэндинг, Пулы, Обратный расчёт) справа |
| Торговля | Открытые позиции и остатки частично закрытых сделок |
| ИТОГО Торговля | Свод по парам: остатки из «Торговли» плюс закрытые части из «Закрытых» |
| Лэндинг, ИТОГО Лэндинг | Дизайн-копии листов Торговли (демо-данные) |
| Пул, ИТОГО ПУЛ | Дизайн листов для пулов (модель закрытия пулов оставлена на потом) |
| Закрытые | Закрытые части частично закрытых сделок и полностью закрытые сделки |
| ИТОГО | Дизайн-копия «ИТОГО Торговля» |
| Справочники | Списки для выпадающих меню (Протокол, Действие в Торговле) |

## Структура репозитория

- `CryptoJournal_Input_Prototype_v7.xlsx` — рабочая таблица.
- `specs/` — дизайн листов: `Дизайн Ввод.md` (общий дизайн «Ввода»), `Дизайн Ввод — Основные данные.md`, `Дизайн Ввод — Разделы.md`, `Дизайн Торговля и ИТОГО Торговля.md` (остальные листы).
- `architecture/` — логика: `Архитектура Ввод — Основное меню.md`, `Архитектура Торговля.md`.
- `promt/` — промт проекта для работы с ассистентом (`Промт проекта.md`).
- `skills/` — пока пусто.

Если документы расходятся: визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## Ключевые правила

- **Дата** везде в формате `ГГГГ.ММ.ДД`.
- **Пара** собирается автоматически из Актива 1 и Актива 2 (`SOL/USDT`), вручную не вводится, окрашена в #FFF2CC. Актив 1 и Актив 2 не могут совпадать.
- **Списки** «Протокол» и «Действие» берутся из листа «Справочники».
- **Сумма (авто)** в Торговле = Кол-во × Курс × (1 − Комиссия / 100). Комиссия по умолчанию 0.2 (в процентах, знак «%» не пишется).
- **ID сделок:** `T-0001` (Торговля), `L-0001` (Лэндинг), `P-0001` (Пул). Нумерация отдельная для каждого раздела, удалённые ID не используются повторно.
- **Раздел записи** определяется заполненным блоком (Тип убран): вводить можно только в один раздел.
- **Открытые и закрытые сделки:** остаток остаётся в «Торговле», закрытая часть уходит в «Закрытые» (ID повторяется, суммы не задваиваются); полностью закрытая сделка есть только в «Закрытых». Частично закрытые сделки подсвечены фоном #FDE9D9.
- **Обратный расчёт** — калькулятор, в журнал не записывается.
- Лист «Ввод» защищён без пароля: редактируются только окна ввода.
