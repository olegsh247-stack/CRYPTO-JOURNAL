# CRYPTO-JOURNAL

Crypto Trading Journal: журнал сделок в Excel (торговля, лэндинг, пулы ликвидности). Репозиторий содержит рабочий Excel-прототип, описание дизайна и архитектуру логики.

## Статус

Этап прототипа и архитектуры. Интерфейс и согласованная логика полей готовы в таблице; **макросы (VBA) и рабочие кнопки делаем в самом конце**. Целевая версия Excel — 2021.

## Основной файл

`CryptoJournal_Input_Prototype_v7.xlsx` — единственная рабочая версия. Старые версии удалены, они сохранились в истории git.

| Лист | Назначение |
|---|---|
| Ввод | Форма ввода: основные данные слева, разделы (Торговля, Лэндинг, Пулы, Обратный расчёт) справа |
| Торговля | Открытые позиции и остатки частично закрытых сделок, Break even по каждой позиции |
| ИТОГО Торговля | Свод по парам: остатки из «Торговли» плюс закрытые части из «Закрытых», P&L, P&L% и Break even по паре |
| Лэндинг | Точная копия «Торговли» (ID `L-…`, Break even); закрытые сделки уходят в общий лист «Закрытые» |
| ИТОГО Лэндинг | Точная копия «ИТОГО Торговля»: свод по парам из «Лэндинга» плюс строки `L-…` из «Закрытых», P&L, P&L% и Break even |
| Пул | Журнал пулов ликвидности: одна строка = один пул (Открыто, Закрыто, Дельта 1 и 2), пул закрывается целиком один раз |
| ИТОГО ПУЛ | Свод по парам: Открыто, Закрыто, Дельта и условная сделка Buy/Sell из дельт |
| Закрытые | Закрытые части частично закрытых сделок и полностью закрытые сделки; общий для Торговли (`T-…`) и Лэндинга (`L-…`), P&L и P&L% |
| ИТОГО | Дизайн-копия «ИТОГО Торговля» |
| Справочники | Списки для выпадающих меню (Протокол, Действие в Торговле) и таблица «Счётчики ID» (последний выданный номер по разделам: T, L, P) |

## Структура репозитория

- `CryptoJournal_Input_Prototype_v7.xlsx` — рабочая таблица.
- `specs/` — дизайн листов: `Дизайн Ввод.md` (общий дизайн «Ввода»), `Дизайн Ввод — Основные данные.md`, `Дизайн Ввод — Разделы.md`, `Дизайн Торговля и ИТОГО Торговля.md` (остальные листы), `Промт Торговля.md` (подробный промт листа «Торговля»), `Промт ИТОГО Торговля.md` (подробный промт листа «ИТОГО Торговля»), `Промт Лэндинг.md`, `Промт ИТОГО Лэндинг.md` (дубли для Лэндинга), `Промт Пул.md`, `Промт ИТОГО ПУЛ.md`.
- `architecture/` — логика: `Архитектура Ввод — Основное меню.md`, `Архитектура Торговля.md`.
- `prompts/` — промт проекта для работы с ассистентом (`Промт проекта.md`).
- `skills/` — пока пусто.

Если документы расходятся: визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## Ключевые правила

- **Дата** везде в формате `ГГГГ.ММ.ДД`.
- **Пара** собирается автоматически из Актива 1 и Актива 2 (`SOL/USDT`), вручную не вводится, окрашена в #FFF2CC. Актив 1 и Актив 2 не могут совпадать.
- **Списки** «Протокол» и «Действие» берутся из листа «Справочники».
- **Сумма (авто)** в Торговле: Buy = Кол-во × Курс × (1 + Комиссия / 100), Sell = Кол-во × Курс × (1 − Комиссия / 100). Комиссия по умолчанию 0.2 (в процентах, знак «%» не пишется).
- **ID сделок:** `T-0001` (Торговля), `L-0001` (Лэндинг), `P-0001` (Пул). Нумерация отдельная для каждого раздела, удалённые ID не используются повторно.
- **Раздел записи** определяется заполненным блоком (Тип убран): вводить можно только в один раздел.
- **Открытые и закрытые сделки:** остаток остаётся в «Торговле», закрытая часть уходит в «Закрытые» (ID повторяется, суммы не задваиваются); полностью закрытая сделка есть только в «Закрытых». Частично закрытые сделки (Торговля и Лэндинг) подсвечены фоном #FDE9D9. Закрытые сделки Лэндинга лежат в том же листе «Закрытые» с ID `L-…`.
- **Автофильтр** на строке меню оставлен на всех листах с таблицами (у всех колонок).
- **Обратный расчёт** — калькулятор, в журнал не записывается.
- Лист «Ввод» защищён без пароля: редактируются только окна ввода.

## Открыто

- Break even в «Закрытых» не считается (колонка убрана); P&L и P&L% рассчитаны на всех листах Торговли и Лэндинга.
- Пулы: частичное закрытие не предусмотрено (пул закрывается целиком один раз); действие закрытия на «Вводе» называется «Закрыть» (список «Добавить, Закрыть»); P&L по пулам не считается (`specs/Промт Пул.md`, п. 10).
- Наполнение и согласование справочников (в том числе активы и Библиотека).
- Правила закрытых сделок Лэндинга (общий лист «Закрытые»): подсветка и своды работают, перенос строк между листами делает этап VBA.
- Протоколы PancakeSwap и Orca из демо-данных «Пула» пока не внесены в «Справочники» (вносятся позже).
- Макросы: ЗАПИСАТЬ, ОЧИСТИТЬ, присвоение ID (счётчики уже лежат на «Справочниках») и переносы между листами, раскрытие списков по клику.
