# Промт проекта CRYPTO-JOURNAL

Рабочий промт для ассистента, который помогает вести проект Crypto Trading Journal (журнал сделок в Excel). Описание проекта, листов и ключевых правил — в `README.md`.

## Контекст

- Репозиторий: `olegsh247-stack/CRYPTO-JOURNAL`, ветка `main`.
- Рабочий файл: `CryptoJournal.xlsm`, версия Excel 2021 (подсказки при вводе актива не делаются).
- Дизайн описан в `specs/`, логика — в `architecture/`. Визуальные правила — в `specs/`, логика полей и сделок — в `architecture/`.

## Правила работы

1. Отвечать по-русски.
2. Сначала изучить репозиторий и документы, затем предлагать. Если пользователь пишет «изменения пока не делаем», ничего не менять, а изложить, как понято и что предлагается.
3. Изменения вносить в `main`. Основной дизайн листов не трогать, только наполнять, если не сказано иное.
4. Макросы лежат в `macros/modTrade.bas`; файл `.xlsm` собирается `python3 tools/mkxlsm.py` из исходника в `archive/`, правки листов делаются в исходнике. Код VBA: `Option Explicit`, константы только в начале модуля, не читать имя функции в правой части выражения, макрос пишет только в незаблокированные ячейки. Формулы допускаются только для согласованных автоматических полей.
5. После правок таблицы пересчитать её и проверить, что нет ошибок в ячейках. Обновить `specs/` и `architecture/`, чтобы документация совпадала с файлом.
6. В корне репозитория одна рабочая версия таблицы; старые версии лежат в `archive/`.
7. Не сохранять в репозитории и документах токены и другие секреты.

## Принятые решения

- Дата `ГГГГ.ММ.ДД`. Написание: Лэндинг.
- Поля «Тип» нет. Раздел записи определяется заполненным блоком.
- «Пара (авто)» и другие автоматические поля: заливка #FFF2CC, ячейки заблокированы.
- ID: `T-0001`, `L-0001`, `P-0001`; нумерация по разделам, удалённые ID не восстанавливаются.
- Частично закрытая сделка: остаток в «Торговле», закрытая часть в «Закрытых», подсветка #FDE9D9.
- «Обратный расчёт» только для расчёта.
- Сумма в Торговле: Buy = Кол-во × Курс × (1 + Комиссия / 100), Sell = Кол-во × Курс × (1 − Комиссия / 100).
- Закрытые сделки Торговли и Лэндинга лежат в общем листе «Закрытые» (ID `T-…`, `L-…`); «ИТОГО Торговля» и «ИТОГО Лэндинг» берут из него строки по букве ID.
- Автофильтр на строке меню оставлен на всех листах с таблицами (у всех колонок).
- P&L и P&L% считаются только по полностью закрытым позициям; у частичных закрытий в «Закрытых» P&L = 0, а снятая прибыль уменьшает Break even остатка (`architecture/Архитектура Торговля.md`, раздел 9).
- Режим записи в «Торговлю» и «Лэндинг» определяют ID позиции и Действие: ID пусто — новая позиция, ID заполнен и Действие противоположное — закрытие, то же — увеличение; закрытие задаётся полем «Закрыть» (Частично — списывается введённое Кол-во, Полностью — весь остаток). Курс пишется не более чем с 8 знаками.
- «ИТОГО» — общий свод Торговли и Лэндинга (пулы не входят); у листа «Пул» есть колонка «Статус» (Открыт / Закрыт), действия пулов на «Вводе»: Добавить, Частично, Закрыть; у пула есть диапазон Min/Max (оба или ни одного, пусто = Web2).
- Адреса «Ввода»: Дата B5, Актив 1 C5, Актив 2 D5, Пара E5, Протокол F5 (необязателен), Статус G5; Торговля C8:C13, Лэндинг E8:E13, Пул G8:G13; Обратный расчёт B17:D17, Комиссия E17.
- Новые монеты и пары добавляются макросом автоматически (список «Монеты» на «Справочниках», листы ИТОГО).
- Поле «Комментарий» убрано. Защита листов без пароля.
